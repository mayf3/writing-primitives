# Voice & Texture：中文自然表达与真实对话（按需）

**状态：vNext 编辑假设 / 未经受控实验验证。** 本文是 U（表达）与 R（关系）的可选编辑协议，**不增加顶层原语**，也不放宽 D（作者约束）及 C（事实、来源、归属和范围）。

## 何时使用

当 D.medium 是口播、演讲、对谈、写给普通读者的非虚构，或作者明确反馈“像公文、像翻译、像轮流读大纲”时启用。正式报告、论文、法律与风险说明也可以审语言，但不能以“必须像聊天”为目标。**“AI 味”是笼统的主观标签；应定位具体导致理解、可听性或作者声音受损的 U，而不是只凭禁词表批量替换。**

### 三项相互独立的检查

1. **Meaning fidelity**：候选表达是否仍忠于 C 的 scope / modality / attribution / source，以及关键 R？若不等价，则候选失败，不因“更顺口”放行。
2. **Voice fit**：它是否符合当前 D 的媒介、受众、说话人和作者确认的语气？没有作者给出的声音参考时，不编造“本人惯用语”。
3. **Natural delivery**：是否能顺畅读出，指代、重音、停顿和句子长短是否帮助听者理解？这通常是编辑判断，除非有真人朗读/听众反馈，否则不标为实测。

**不是每个后台限定都必须逐字讲给受众听**：如果限定仅用于避免作者越界、并不改变当前句子的可理解范围，保持内部 guard 即可；如果省略后读者会合理误解事实强度或结论，则应在当句或合适的上下文明确表达。

如果一个限定无法在一句话内自然表达，可以**换成两句、调整信息顺序，或者保留原来的精确写法**；不能为了流畅删去必要不确定性。

## 四类常见可诊断问题

### 1. 元语言与过度免责

风险：把 C.scope / C.modality 直接朗读成“需要指出的是……不能据此断言……”；连续使用此类句式会压住叙事和说话人声音。

**不是禁用句型**：有些重要论证需要明确写“不能据此推断”。只在反复、冗长或不符合媒介时提出局部替代。

**纯虚构示例**：

- 原句：“当前画面只显示任务已启动，不能据此认定任务已完成或成果已经核验。”
- 口播候选：“屏幕上写着‘运行中’。那只能说明它启动了。做完没有、结果对不对、有没有人验收，得分开看。”

核对：候选仍只有“已启动”的信息；未凭空声称系统失败、消息未送达或结果正确。注意“后续没有检查”和“还不能确定”不同，不能互换。

### 2. 形式动词、名词化与抽象词簇

“进行讨论、实现提升、具备能力、存在问题”可提示进一步观察，但**这些词本身不构成错误**。只有在遮蔽真实动作或增加听力负担时，才尝试具体动词。

- 原句：“志愿者对活动安排进行了调整，随后开展了交流环节。”
- 候选：“志愿者把介绍缩短了，接着请大家各选一句话聊聊。”

**前提**：已提供的材料确实包含“介绍缩短”和“选一句话”；如果原文只说“调整”，不得凭语言习惯编出具体做法。

### 3. 匀速句式与机械路标

连续相同长度的总结句、过多“首先/其次/从而/这意味着”可能令口播像朗读提纲。但**不设“每个长句后必须跟 2–6 字短句”之类机械配额**；可以用省略、短问、直陈、留白或保持原样。段落顺序有真实逻辑时，路标也可能有用。

### 4. 对谈被写成报幕接力

检查 U 的 speech action 和 R.replies_to：某次发言是否真正回应了上一轮的意思，而非机械把下一张提纲读出来？

有意义的接力动作包括：补充遗漏、核实理解、提出边界问题、承认并更新看法、用日常类比试探、发现反例、纠正误解、交出新证据、接住对方的真实感受。**分歧不是必要条件**，也不要求每轮都有认知摩擦。

**虚构示例**：

- 生硬接力：
  - 甲：“传感器能读到插入位置的湿度。”
  - 乙：“很有意思，那么它还有什么特点？”
- 有内容的接力：
  - 甲：“那它报干，是不是整盆都缺水？”
  - 乙：“还真不能。它只测到插进去的那一小块。”
  - 甲：“原来我把一个位置当成了整盆。那我至少得想想插在哪儿。”

以上是**演示写法**，不是已测试的自然对话。真实对谈也允许“嗯，我听懂了”，不能强制每次反问或抬杠。

## 最小 Voice Pass（不是全文清洗）

1. 读 D、当前版本 U；先选 **1–3 个**实际影响口播或声音的局部问题。没有问题可直接停止。
2. 锁定该处 C/R 的可保留语义、来源、确定性与角色归属；列出高承载 U 的作用。
3. 生成一到两个**可逆的局部候选**。优先让具体动作承载含义；禁止编造动作、情绪、历史经历或作者口头禅。
4. 做 **semantic back-check**：逐项回答“谁说的、发生什么、范围多大、确定到什么程度、因果或回应有没有改变”。有不一致就回退候选。
5. 读回上下文及必要后文，检查新候选没有造成重复解释、声音同质化或旧错误回归。
6. 交作者选择；只有真实读回/受众试听才记为相应的观察。没有真实观察时写“编辑预测”，不写“听众已觉得自然”。

若必须改变 C/R 才能自然讲清楚，**升级为结构修改提议，保留原约束，由作者决定**；不能借“语感修补”静默改动含义。

## 不该自动执行的规则

- 禁止所有“不能据此推断”；
- 逢“进行/具备/存在”就替换；
- 每段都要一句惊叹或短反问；
- 每一轮发言都要反驳、制造冲突；
- 把所有说话人写成同一个活泼幽默的人；
- 通过添加亲历、自嘲、失败故事来换取“人味”；
- 把更短、更激烈、更像网络流行语当作天然更好。
