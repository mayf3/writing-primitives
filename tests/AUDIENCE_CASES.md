# 听众价值与体验检验：设计 / Not Run

**没有执行模型对照、真人试听或统计效果验证。** 本文件测试编辑行为与受众假设，不把自编的“好稿”自动当作金标准。它是原有评测的可选扩展，不是另建一套强制评分体系。

## 1. 分开记录结果、理解与关注

**结果收获：** 按 D 选择复述、迁移判断、人物/处境辨认或体验反馈，不强制所有作品接受知识测验。迁移题写清新情境事实，不用模糊真实产品状态或高风险操作去测试。先了解参与者已有知识，允许不同但有依据的答案；只会复述或不能复述某一句，都不是价值已兑现/未兑现的充分条件。

**过程理解：** 真正的前缀测试只提供停点之前的正文，不泄漏后文、摘要、作者预期答案。记录参与者怎么理解、哪里需要回看，不要求其下一个问题恰好等于作者 handoff。读过全文再模拟“此前的我”只能叫编辑推断。

**持续关注/停留：** 与理解分开问“愿意继续或停留吗，为什么”，记录具体位置与体验；可连续听后回访，也可单独做停点测试。停点提问本身可能改变体验，不能把被迫回答问题等同自发好奇。平静、共鸣、欣赏等也可能是目标，不只测悬念。没有标记既不证明掉线，也不证明没有问题。

1–3 位读者的原话可作为探索性观察记录，不足以证明普遍改善。完播、愿意继续、复述正确分别有含义，不合成一个“感染力分”。没有真人时仍可核查事实/文本缺口，但受众效果标 not_tested。

## 2. 比较候选而非指定赢家

使用 [固定材料与 A/B 候选](../examples/AUDIENCE_VALUE_COMPARISON.md)。评审先对照材料找语义变化，随后在不知道版本标签的条件下评议；最好与改写者的自评分离。A 同样可能支持迁移，B 也可能啰嗦。记录长度、朗读时长、调用/人工成本；不同材料或 D 不纳入同一效果归因。不能把“B 应获零主问题”写成验收条件。

已独立核对的事实矛盾可有明确 gold issue；自然性、价值和合理多解应保留评审分歧。强普通提示词、Light IR、加入听众视角的候选应共享材料与预算；需要检验新规则成本而非只比较评语长度。

## 3. 场景设计（不是已生成完整 benchmark）

| ID | 场景 | 期望行为 | 不可接受行为 |
|---|---|---|---|
| AV01 | D 要求解释关键区分，正文遗漏其中一项 | 锚定缺失的内容并建议补充有依据的解释 | 只润色句子或宣称真人一定没听懂 |
| AV02 | 稿子正确顺畅，但对目标受众的相关性没有文本线索 | 标编辑假设，比较已有材料的相关性，不强判普遍无趣 | 加无据恐吓或虚构痛点 |
| AV03 | 执行结束被推成已有结果 | 按固定材料识别蕴含错误 | 因表达顺口而放行 |
| AV04 | 改写者宣称自己的 B 是完美正例 | 独立核验，允许 A 更好或两者都可用 | 预设 B 必须零问题 |
| AV05 | D 是记录/审美/陪伴而非教学 | 按自身目标检查，不强加判断清单 | 强迫认知升级或将该体裁整体免检 |
| AV06 | 用户只要求改一句口播，D 已确认 | 限定改动范围，方向问题单独说明 | 每轮重开选题、静默降低承诺 |
| AV07 | 用户明确要求探索值得讲的角度 | 给少量 proposed D，说明现有材料支撑与代价 | 把旧 D 锁死，或把候选当作者已确认 |
| AV08 | 两位读者没有标记/意见不同 | 保留原话、未知与分歧，按目标继续判断 | 一律不改或一律认定走神 |
| AV09 | 模型已见全文却声称做前缀实验 | 降为 editor_inference，另开隔离调用才测前缀 | 伪造 model_prefix_prediction |
| AV10 | B 增加一倍篇幅或新增事件后更受欢迎 | 记录成本和材料差异，限制因果归因 | 将改进全归给新增审稿协议 |
| AV11 | intended_progress 写了“读者获得判断方法” | 回查具体 U，再把真人效果另列 | 计划字段自证已兑现 |
| AV12 | 多改一个段落比改一个限定词更保真 | 比较有效性、语义风险和返工，允许结构候选 | 机械选择字数最少/层级最浅的修改 |

## 4. 本轮减重与试写的回归场景（未执行）

| ID | 场景 | 期望行为 | 不可接受行为 |
|---|---|---|---|
| AV13 | 一个条件推论没有找到反例，但另一个数量/归属已被改写 | 分别核对，不把局部检查当全面证明 | 宣称反事实单问可 100% 放行 |
| AV14 | 作者要探索正文中部的表达，旧稿没有硬错误 | 给能展示差别的可逆片段 | 必须证明材料浪费，或只允许写开头100字 |
| AV15 | 固定材料虚构改写新增身体动作；另一次任务允许自由虚构 | 区分两次授权和材料版本 | 虚构一概可随便添，或一概禁止创作细节 |
| AV16 | 作者未回应一个备选，后来提供新材料并要求探索 | 不视为已采用，但响应新的请求 | 永久关闭方向讨论 |
| AV17 | 非教学片段只有动作、处境和自然结束 | 按 D 检查，允许不用 current_question | 强制分类、提炼三条方法或自动免检 |

对照 [小范围试写](../examples/SMALL_PROBE_AND_NARRATIVE.md) 时，不预设哪个候选是“正确自然”的金标准。作者自读不是盲测；按文中约定答题不能完全排除先验或提示。日常个人选稿与方法效果研究可以采用不同证据要求，不把“可以现在选稿”写成“已证实普遍有效”。

## 5. 最小实验记录

保留任务与稿件版本、D 是否确认、固定材料、候选的完整文本及修改、预算/时长、评审隔离方式、参与者起点与数量、实际问题、原话/答案和分歧。事实核对、模型推断、作者选择、真人观察分别标明。若没有运行，记录 not_run；不得填“通过率”或宣称价值已普遍验证。
